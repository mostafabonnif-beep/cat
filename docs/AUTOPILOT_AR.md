# وضع التشغيل الآلي الكامل

شغّل المشروع من الطرفية مع:

```bash
python main_improved.py --autopilot --url "رابط_يوتيوب"
```

وضع `--autopilot` يفعل تلقائياً:

- مراجعة AI للسياق، وليس مطابقة الكلمات فقط.
- تحديث معجم السياسات المحلي.
- فحص الكلام الظاهر داخل الفيديو عبر OCR عندما يكون Tesseract مثبتاً.
- فحص الوجه والمتحدث النشط.
- فحص إعادة الاستخدام بين كل المشاريع عبر بصمة الفيديو.
- فحص الحقوق والتحويل التحريري.
- فحص الصوت، الموسيقى، البيانات الوصفية، والمحتوى البصري.
- إيقاف النشر عند نقص الدليل أو فشل أي بوابة حماية.

الوضع الصارم يحتاج Gemini أو G4F. مع Gemini يمكن وضع `GEMINI_API_KEY` في متغير بيئة أو في إعدادات المشروع. إذا لم يوجد محرك AI، يتوقف التشغيل بدلاً من المتابعة بتخمين.

التقارير التي يجب مراجعتها قبل النشر:

- `risk_scorecard.json`
- `provenance_report.json`
- `ocr_safety_report.json`
- `audio_qc_report.json`
- `publish_blocklist.json`

لا توجد قائمة كلمات رسمية ثابتة من YouTube؛ المعجم المحلي مصدره قابل للتدقيق، لكن القرار النهائي يعتمد على السياق والنية والصوت والصورة، وليس على كلمة منفردة.

قبل بدء أي معالجة، يجري الوضع فحص جاهزية تلقائياً: FFmpeg وFFprobe وTesseract بالعربية والإنجليزية والنموذج البصري ومحرك الذكاء الاصطناعي. عند غياب أي متطلب حرج يتوقف قبل استهلاك الوقت ويكتب `autopilot_readiness.json` داخل المشروع.

بعد الفحص ينشئ النظام تلقائياً `review_queue.json` و`review_queue.html`، مرتبة حسب الخطورة، حتى لا يضيع أي مقطع يحتاج قراراً بشرياً قبل النشر.
