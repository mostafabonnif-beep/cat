# سجل الحماية المحلي

أصبح المشروع يستخدم SQLite محلياً كسجل أدلة لا كقاعدة بيانات سحابية. هذا الاختيار يحافظ على الخصوصية، يعمل دون شبكة، ويتحمل تشغيل أكثر من عملية بفضل WAL.

السجل يحفظ:

- بصمة المقطع ووقت نافذة المصدر.
- نتيجة بطاقة المخاطر لكل مقطع.
- أسباب حجب الكراهية أو التحريض أو التكرار.
- مسار المشروع فقط، ولا يخزن ملفات الفيديو داخل قاعدة البيانات.

المسار الافتراضي هو `.oussama_content_registry.sqlite3` داخل مجلد المشروع. للمشاركة بين كل المشاريع، ضع المسار في المتغير `OUSSAMA_CONTENT_REGISTRY`، مثلاً:

```bash
OUSSAMA_CONTENT_REGISTRY=/path/to/oussama-ledger.sqlite3
```

لعرض الملخص:

```bash
python -m scripts.content_ledger --project /path/to/project --summary
```

تظل قاعدة `content_guard` الحالية هي صاحبة قرار منع النشر. سجل الأدلة الجديد يكملها ويجعل نتيجة الفحص قابلة للتدقيق عبر المشاريع.
